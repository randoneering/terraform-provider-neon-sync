# adding-neon-resource

## Overview

Net-new resources on terraform-plugin-framework land through a fixed ten-file shape, in a fixed order, against a fixed test surface. The openspec change is the source of truth for what gets built; code mirrors it.

## When to Use

- New `neon_*` resource requested for the first time.
- Porting an SDK v2 resource to framework.
- Adding a data source that mirrors a resource.

Not for: bug fixes in existing resources, refactors of CRUD, or schema additions to shipped resources (open a normal PR).

## Core Pattern

Ten files, in this order. Skip nothing.

1. **openspec change first.** Create `openspec/changes/add-neon-<name>/` with `proposal.md`, `design.md`, `tasks.md`, and `specs/neon-<name>/spec.md`. No code before proposal lands.
2. **`provider/resource_<name>.go`.** Interface asserts (`Resource`, `ResourceWithConfigure`, `ResourceWithImportState`, `ResourceWithModifyPlan`). Model struct with `tfsdk:` tags only on Framework-facing fields. `Metadata`, `Schema`, `Configure`, `Create`, `Read`, `Update`, `Delete`, `ImportState`, `ModifyPlan`. Wrap every API call in `projectReadiness.RetryFramework` (plain) or `projectReadiness.RetryWithFallbackFramework` (per-status-code fallbacks, e.g. 404 → `RemoveResource`).
3. **`provider/acc_<name>_test.go`.** Minimum four subtests: create + read, update-or-no-update (forced replace), import, out-of-band deletion. Use `newProviderFactories` (plural — see Quick Reference).
4. **Register in `provider/provider.go`.** Add `NewNeon<Name>Resource` to the `Resources(...)` slice, alphabetically placed (bucket, function, service_credential, then new).
5. **`examples/resources/neon_<name>/resource.tf`.** Hand-written; the doc template embeds it via `{{ tffile }}`. Match the schema's exact attribute names — no invented attributes.
6. **`templates/resources/<name>.md.tmpl`.** Header frontmatter + `{{ tffile ... }}` + `{{ .SchemaMarkdown }}` + Import block.
7. **`docs/resources/<name>.md`.** Generated by `make docu`. Do not hand-edit.
8. **`CHANGELOG.md`.** New minor version section above `[Unreleased]`. Note SDK bump if `go.mod` changed.
9. **Verify:** `go vet ./...`, `go build ./...`, `go test ./provider/... -short`, then `make testacc` with `TF_ACC=1` and `NEON_API_KEY`.
10. **PR.** Local commit on a feature branch; PR gated on user permission per AGENTS.md.

## Quick Reference

| Convention | Value |
|---|---|
| Framework types in model struct | `types.String`, `types.Bool`, `types.Int64`, `types.Map{StringType}`, `types.List{...}` |
| Internal helpers, SDK wrappers, FSM inputs | Go standard library types (`string`, `int`, `map[string]string`, `time.Time`) |
| Forced-replace helper | `stringChanged(a, b types.String) bool` from `provider/helper.go` |
| FSM entry | `projectReadiness.RetryFramework` / `RetryWithFallbackFramework` |
| Acceptance provider factory | `newProviderFactories` — the only factory in this fork (defined at `provider/provider.go:175`) |
| Composite ID | `<project_id>/<branch_id>/<name>` |
| Sensitive attributes | `Sensitive: true` on the schema + never logged via `tflog` |

## Common Mistakes

- **Writing code before the openspec proposal.** Reverts cleanly only if caught in PR review; otherwise the openspec archive becomes inconsistent.
- **Mixing `types.String` and `string` in the model struct.** The model must be all Framework types so `req.Plan.Get`/`req.State.Get` work. Go-native `string`/`int`/`time.Time` belongs in helper structs, SDK wrappers, FSM callbacks, and `tflog` calls.
- **Reaching for `types.String` outside the model struct.** Framework types exist to bridge HCL into the model. Anywhere else — internal helpers, SDK wrappers, FSM inputs, log payloads — Go standard types are simpler and skip null-handling ceremony. Rule: if a value is not on the schema, do not wrap it in a Framework type.
- **Reading test fixtures from the SDK instead of from `*terraform.State`.** Inside a `Check` block, every assertion reads `state.RootModule().Resources["neon_<name>.this"].Primary.Attributes["<attr>"]`. Round-tripping through `client.ListProjects` to find a project we just created is the pattern this skill replaces. The `t.Cleanup` SDK sweep stays — Terraform state is gone by then.
- **Forgetting ImportState or the import subtest.** Every framework resource has one. Test the `<project>/<branch>/<name>` composite form.
- **Forgetting the out-of-band deletion subtest.** Resource deleted in Neon without Terraform; next `terraform plan` must `RemoveResource` cleanly via the 404 fallback in `RetryWithFallbackFramework`.
- **Picking the wrong provider factory.** The only factory in this fork is `newProviderFactories` (plural, defined in `provider/provider.go:175`). Use it. The singular form is historical and not present in the current binary.
- **Skipping `CHANGELOG.md`.** New resource = new minor version section.
- **Hand-editing `docs/resources/<name>.md`.** Regenerate via `make docu`.
